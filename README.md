<tr><td>

`PyTorch` `FFT` `Diffusion Reconstruction`

Which mathematically interpretable signal anomalies best distinguish genuine media from deepfakes across *unseen* generation methods — and does fusing complementary descriptors improve generalisation? Directions: frequency-domain anomalies, diffusion reconstruction error, spatial artefacts, camera-signature inconsistencies.
